# Referencias

Material original generado con Google Flow (Veo 3.1 / Nano Banana) para el juego.
**No se publica con el juego**: sirve como referencia para modelar personajes y pistas.
Las versiones livianas que usa el juego están en `public/assets/`.

- `flow/encargo.md`: el encargo con los prompts base.
- `flow/informe.md`: el informe de lo que se generó.
- `flow/prompts.md`: el prompt exacto de cada archivo.
